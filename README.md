# Личный проект «Сатурн»

* Создатель: Сергей Денисович
* Назначение проекта: тестирование возможностей сайта

---

## О проекте

Данный сайт создан в учебных и тестовых целях.  
На текущем этапе проект представляет собой лендинговую страницу с базовой структурой и оформлением.

Сейчас сайт уже включает:
- главную информационную секцию,
- навигационное меню,
- блок новостей,
- форму обратной связи,
- визуальное оформление с фоновым изображением и стилями.

---

## Текущее состояние

На данный момент проект находится в стадии разработки и тестирования.  
Пока что он имеет функционал лендинговой странички, но в дальнейшем будет развиваться и дополняться новым содержимым, разделами и возможностями.

Планируется:
- улучшение структуры сайта,
- доработка дизайна,
- расширение функционала,
- добавление новых страниц и интерактивных элементов.

---

## Цель проекта

Основная цель проекта — проверить возможности HTML, CSS и базовой структуры сайта, а также постепенно развивать его в более полноценный веб-ресурс.
